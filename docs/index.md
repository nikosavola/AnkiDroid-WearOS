# Wear for AnkiDroid

A Wear OS companion for [AnkiDroid](https://github.com/ankidroid/Anki-Android). See what is due,
read the card, reveal the answer and grade it from your wrist. Reviews are written back into your
own AnkiDroid collection, so AnkiDroid keeps owning the schedule.
